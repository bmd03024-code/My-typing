# My Typing LMS

English QWERTY + বাংলা typing practice, built as a static HTML/CSS/JavaScript app.

## Run / publish
Open index.html locally, or enable GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).

## Current starter release
- Responsive interface and dark/light theme
- English and Bangla 30-day track framework
- Learn and Game phases with inactivity-aware timer
- Practice metrics, local progress, JSON backup
- Admin preview, progress simulation, curriculum import/export

## Important
This is the first pushed foundation, not a claim that every requested feature is complete or verified. The exact Bijoy key map/composition, full 60-day syllabus, animated game mechanics, complete final exam, and printable certificate still need implementation and testing. Admin credentials and progress are stored locally and are not secure. Bangla WPM needs a documented measurement convention; physical-keyboard testing is required for meaningful certification.
